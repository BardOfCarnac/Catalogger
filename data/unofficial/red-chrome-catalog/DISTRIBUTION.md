# Distribution notes — The RED Chrome Catalog

## Attribution

Original homebrew: **The RED Chrome Catalog** by **Dusk#1352 (/u/mitsayantan)**.

Source reference: https://www.reddit.com/r/cyberpunkred/comments/11l2ses/

Vend-R's contribution is the normalization, source separation, identifiers, catalogue relationships, and distribution metadata in this directory.

## What may be packaged

The intended Vend-R distribution contains only the normalized files in this directory. It does **not** include the original RTF/PDF or copied descriptive rules text.

The normalized item records are intentionally limited to catalogue-facing fields such as names, categories, prices, manufacturer identities, and relationship metadata.

## Release gates

Before public redistribution:

1. Record affirmative permission from the original homebrew creator.
2. Change `distribution.status` in `source.json` from `permission-pending` to an approved state and record the permission reference.
3. Keep the pack freely accessible; do not place it behind a purchase or subscription requirement.
4. Keep clear attribution to the original creator.
5. Keep an obvious notice that this is unofficial material and is not approved or endorsed by R. Talsorian Games.
6. Recheck the current R. Talsorian Games Homebrew Content Policy before release: https://rtalsoriangames.com/homebrew-content-policy/

## Separation from official data

This pack must remain distinguishable from official RTG sources in APIs and user interfaces. Recommended source family: `unofficial`; source type: `homebrew`.

Version prepared for distribution review: **0.2.0**.
