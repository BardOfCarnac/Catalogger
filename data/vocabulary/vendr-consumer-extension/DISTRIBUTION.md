# Distribution notes — Vend-R Consumer Extension

This pack is Vend-R-created editorial vocabulary rather than extracted third-party homebrew.

## Distribution boundary

The package may be distributed as a standalone Vend-R source pack. It contains no copied Cyberpunk RED rules text and no original CircleofNoms table data.

The `brand-affinities.json` file contains references to identifiers from the optional CircleofNoms consumer pack. Those references do not make that source pack part of this distribution and must degrade gracefully when it is absent.

## Release conditions

- Keep the package clearly labelled as unofficial Vend-R material.
- Keep it freely accessible while it is distributed as Cyberpunk homebrew/app content.
- Do not present generated brand affinities as canon.
- Recheck the current R. Talsorian Games Homebrew Content Policy before public release: https://rtalsoriangames.com/homebrew-content-policy/

Version prepared for distribution: **0.2.0**.
