# Shop tag crosswalk

The existing 152 shop profiles have 325 distinct known-for descriptions, 132 distinct shop-type labels and 169 distinct trade tags.

The crosswalk in `data/stocking/shop-tag-taxonomy.v1.json` maps conservative merchandise families onto Catalogger's existing source subcategories. Original descriptions remain untouched. Type supplies cautious baseline eligibility, known-for provides preferences, and trade describes commercial behaviour.

Unmatched shop tags are retained for review. Books and printed media have no faithful official catalogue subcategory. Tool-specific retail must not inherit the whole General Gear category without narrower checks.
